# NEO-RONIN: Rift Alchemy

A fast, replayable Pygame arcade-action prototype for the Mavuly Hackathon 2026.

## The idea

In Neo-Edo, 2099, Cyrus broke reality while attempting alchemy. The Rift merged feudal Japan, a cyberpunk future, and a fantasy world. Jor, the last ronin, fights through the Neon Market with Kuro and Shiro.

## Controls

- Choose Jor, Kira, or Nyx
- Move: **A/D** or **Left/Right arrows**
- Attack: **J**, **X**, or **K**
- Switch dog: **T**
- On touch/mobile devices: use the **X** and **DOG** buttons
- Enter/Space starts and restarts runs

## Objective

Survive 75 seconds, collect gold Alchemy Shards, defeat KORP soldiers, fantasy spirits, skeletons, drones, and Kane's werewolf form. Choose Jor, Kira, or Nyx. Kuro attacks while active; Shiro heals once per run.

## Run

```bash
py -3.12 -m pip install pygame
py -3.12 main.py
```

Run from the project directory so the `assets` paths resolve correctly.
